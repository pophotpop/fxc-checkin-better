## 上线 GitHub Pages（5分钟）

1. 注册 [GitHub](https://github.com)（免费）
2. 新建仓库，名字填 `fxc-checkin`，选 **Public**，不要勾选 Initialize
3. 上传 `index.html`、`avatar.png`、`README.md` 三个文件
4. 进入仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` → Save
5. 等约1分钟，访问：`https://你的用户名.github.io/fxc-checkin/`

## 手机快捷方式

在手机浏览器打开网址后：

像 APP 一样使用 ✅

## 数据说明

- 数据存储在手机/电脑的浏览器本地（localStorage）
- 换浏览器或清除浏览器数据会丢失，建议定期截图记录重要积分
- 管理员可在「清除全部数据」前做好截图备份
